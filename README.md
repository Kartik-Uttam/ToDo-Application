## 🚀 About the Project

**Dayflow** is a lightweight To-Do List application designed to make everyday task management easier.

- 📝 Organize daily tasks.
- ✅ Track completed tasks.
- 🎨 Enjoy a clean and modern interface.
- 📱 Use a responsive layout across different screen sizes.
- ⚡ Manage tasks through a simple and intuitive interface.

## ✨ Features

- **Task Management** — Add and manage tasks.
- **Task Tracking** — Mark tasks as completed.
- **Modern UI** — Clean layout with user-friendly controls.
- **Responsive Design** — Adapted for different screen sizes.
- **PWA Support** — Includes a web app manifest and service worker.
- **Caching** — Supports offline resource access when caching is configured.

## 🛠️ Built With

| Technology | Purpose |

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Kartik-Uttam/ToDo-Application.git
```

### 2. Navigate to the project folder

```bash
cd ToDo-Application
```

### 3. Run the application

Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

> For service worker testing, run the application through localhost or HTTPS.

## 📱 Progressive Web App

Dayflow includes files used for Progressive Web App functionality.

- `manifest.json` — Defines the application's name, appearance, and display settings.
- `service-worker.js` — Can cache application resources for faster loading and offline access.

Actual installation and offline functionality depend on the implementation and browser support.
