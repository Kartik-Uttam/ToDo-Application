## 🚀 About the Project

**Dayflow** is a lightweight To-Do List application built to make everyday task management easier.

- 📝 Organize your daily tasks.
- ✅ Keep track of completed tasks.
- 🎨 Enjoy a clean and modern interface.
- 📱 Access the app through a responsive layout.
- ⚡ Experience a lightweight application without unnecessary complexity.

## ✨ Features

- **Task Management** — Add, organize, and manage tasks.
- **Task Tracking** — Mark tasks as completed.
- **Simple Interface** — Navigate through tasks easily.
- **Progressive Web App Support** — Includes a web app manifest and service worker.
- **Offline Support** — Available for resources and functionality supported by the implemented caching strategy.

## ⚙️ Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/Kartik-Uttam/ToDo-Application.git
```

**2. Open the project folder**

```bash
cd todo-app
```

**3. Run the application**

Open `index.html` in your browser, or use the **Live Server** extension in VS Code for local development.

> For testing service worker functionality, use localhost or a secure HTTPS connection.

## 📱 Progressive Web App

Dayflow includes the files needed for Progressive Web App functionality.

- `manifest.json` — Defines application metadata.
- `service-worker.js` — Handles configured caching and offline resource support.

Installation and offline behavior depend on the actual implementation and browser support.
